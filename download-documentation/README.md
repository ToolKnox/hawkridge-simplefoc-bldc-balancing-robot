# Download the documentation

Everything for this build is in this GitHub repository.

1. On the repository front page, click **Code → Download ZIP**, or run `git clone https://github.com/ToolKnox/hawkridge-simplefoc-bldc-balancing-robot.git`.
2. Start with the root `README.md`. It opens with the install and build guide.
3. Firmware, STL files, SolidWorks/STEP CAD and the original upstream documentation are mirrored under `source/upstream/`.
